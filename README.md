# Appknox MCP Server

An [MCP](https://modelcontextprotocol.io) server that connects your AI coding
agent to [Appknox](https://www.appknox.com) KnoxIQ — fetch the vulnerabilities
Appknox found in your app, fix them in your repo, verify each fix with its own
proof-of-concept, and confirm via a re-scan.

> Setup, usage, and tool documentation are added in subsequent changes.
